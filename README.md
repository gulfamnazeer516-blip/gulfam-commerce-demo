# Gulfam Commerce 🛍️

### Modern Responsive eCommerce Store Demo

Gulfam Commerce is a modern, responsive eCommerce frontend application developed using HTML5, CSS3, and JavaScript. Designed to showcase professional online shopping experiences.

## Features

- Modern and responsive storefront
- Product catalog with category filters
- Live product search and sorting
- Add to Cart functionality
- Shopping cart quantity management
- Browser Local Storage support
- Customer checkout form
- Demo order confirmation
- Mobile-friendly design

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage API

## Live Demo

https://gulfamnazeer516-blip.github.io/gulfam-commerce-demo/

## Installation

1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Explore products, add items to cart, and test checkout.

## Important Note

This is a frontend eCommerce portfolio demo inspired by WooCommerce. It does not process real payments or connect to a live WooCommerce backend.
